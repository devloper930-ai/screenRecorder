# ScreenFlow Recorder

A modern browser-based screen recorder with MP4 export.

## Features

- Screen recording
- Window recording
- Browser tab recording
- Microphone support
- System audio support
- Pause / Resume
- Stop recording
- Live timer
- Recording size indicator
- 1080p High quality
- 720p Balanced quality
- 480p Small quality
- Modern responsive UI
- Glassmorphism design
- MP4 export
- H.264 video
- AAC audio
- Fast Start MP4
- Local browser processing
- No server upload
